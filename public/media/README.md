# Admin media

- `brand/` - logo versions copied from the customer site (`logo-800.png` for the sidebar and login card, `logo-mark.png` for the collapsed sidebar, favicons).
- `auth/login-bg.jpg` - optional photo behind the login card, 1920x1080, max 400 KB.

Keep `brand/` identical to the customer site's `public/media/brand/`.
